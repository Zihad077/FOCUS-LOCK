Install

  1. Tap Download APK. Your browser may warn that this type of file can be harmful. Choose to keep it.
  2. Open the file. If asked, allow your browser to install unknown apps.
  3. Install and open FocusLock.
  4. Grant the permissions below when the app asks.

Permissions

  • Usage access: to measure how long you use each app.
  • Accessibility service: to detect which app is open and show the lock screen. It is not used to read your messages or passwords.
  • Display over other apps: to show the block screen.
  • Notifications: for limit warnings and focus alerts.
  • Do Not Disturb access (optional): to silence notifications during Focus mode.
  • Internet: for ads in the free version and for Premium payment checks.

Help

The app will not install

Check that you have Android 7.0 or newer and enough free space. Allow installs from unknown apps for your browser or file manager.

The block screen does not appear

Open Settings, then Permission Center, and make sure Usage access, Accessibility and Display over other apps are all granted.

The download does not start

Try another browser or network. You can also get the file from GitHub.
